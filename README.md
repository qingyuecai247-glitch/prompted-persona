# Prompted Persona

Research-code repository for “Language model personas express traits but not human personality dynamics”.

Repository setup is in progress. The code upload is pending review; only this README is currently published. Do not yet use this repository as the paper’s complete code-availability link.

The prepared public snapshot excludes study observations, named-persona records, questionnaires, situation datasets, model weights, server logs and server environment snapshots. Full reviewer materials are maintained separately by the authors.

A project-wide code license has not yet been selected. No complete reproducibility release is claimed.
